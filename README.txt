MEILIEX MINI APP — GitHub Pages Package

วิธีอัปโหลด
1. เปิด Repository: mbot-mini-app
2. ลบไฟล์เวอร์ชันเก่าออกจากหน้า Repository
3. อัปโหลดไฟล์ทั้งหมดภายในโฟลเดอร์นี้ (อย่าอัปโหลดเฉพาะไฟล์ ZIP)
4. กด Commit changes
5. รอ GitHub Pages ประมาณ 1–3 นาที แล้วเปิดหน้าเว็บใหม่

เปลี่ยนรูปกิจกรรม
- เตรียมรูปสี่เหลี่ยม 1:1
- ตั้งชื่อไฟล์ activity.png
- อัปโหลดไว้ตำแหน่งเดียวกับ index.html

แก้สถานะไลฟ์
- เปิด index.html
- ค้นหาคำว่า const streamers
- เปลี่ยน live:true สำหรับคนที่ไลฟ์
- เปลี่ยน live:false สำหรับคนที่ออฟไลน์

หมายเหตุ
- ลิงก์ Telegram ใน communityLinks ยังว่างอยู่ ต้องใส่ลิงก์จริงภายหลัง
- สถานะในแพ็กเกจนี้เป็นแบบแก้ไขเอง ยังไม่เชื่อม Twitch API แบบ Real-time
